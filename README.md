I enjoy building software I can use every day, from local AI assistants and music discovery to coding practice and vehicle maintenance. My interests center on **AI agents, machine learning, and backend development**, with a focus on making the pieces work reliably together.

My current focus areas include:

- 🧩 **Machine learning:** Building recommendation algorithms and evaluation pipelines for music discovery with Audino.
- 🐢 **Application development:** Designing APIs, data storage, desktop interfaces, and automated tests.
- 🌿 **Linux & self-hosting:** Learning infrastructure through my homelab, containers, storage, and networking.

## 🍀 Projects

**[AM — Local AI Coding Practice](https://github.com/Ejozef13/AM)**

A browser-based study app that turns topics and notes into debugging exercises for Python, Java, C, and C++. Combines structured LLM generation, blind review, and execution checks with restricted Docker runners and SQLite-backed progress, drafts, and review scheduling.

**[April — Local AI Agent & Voice Companion](https://github.com/Ejozef13/April)**

A Python/FastAPI assistant connecting Whisper, Ollama, and Piper with source-cited web search, approved-folder retrieval, and editable persistent memory. Includes a browser interface and optional Qt tray companion, with bounded tool use, cancellation, and recovery. The desktop voice workflow is user-tested; personal email/calendar acceptance and Raspberry Pi deployment are in progress.

**[Audino — Machine Learning for Music Discovery](https://github.com/Ejozef13/Audino)**

A Python/NumPy/SQLite recommendation and listening analytics prototype. Implements implicit-feedback ALS, popularity and artist-affinity baselines, and chronological evaluation with Recall@K and NDCG@K. Includes validated event imports, a dashboard, and listening summaries. Current experiments use synthetic data; real-data evaluation and a live Navidrome connection are next steps.

**[Auto-Maintenance — Multi-Car Service Tracker](https://github.com/Ejozef13/Auto-Maintenance)**

A Python/Tkinter desktop app with vehicle-specific service records, searchable history, and CSV export. Separates storage from the interface and includes input validation, integer-cent costs, backups, temporary-file replacement, and legacy-data migration.

## 🌳 Homelab

My **[self-hosted homelab](https://github.com/Ejozef13/server)** is where I explore Linux, virtualization, storage, and networking by running services I actually use.

- **Compute & storage:** Proxmox virtual machines, TrueNAS/ZFS, and authenticated SMB shares.
- **Self-hosted services:** Debian and Docker Compose running Jellyfin and Navidrome, with persistent volumes and startup dependencies.
- **Networking:** A dedicated WireGuard VM with nftables forwarding rules; tunnel access is tested on the local network, with outside-home access planned.
- **Local AI & monitoring:** Additional experience with Ollama, Open WebUI, Qdrant, AMD ROCm, Prometheus, and Grafana.
